# Klinik Psikolog Dilara Saçal — Site başlangıç paketi

## Yayınlama
1. GitHub üzerinde PUBLIC yeni bir depo oluşturun (ör. `dilara-website`). README ile başlatmayın.
2. ZIP dosyasını bilgisayarınızda açın. `dilara-site` klasörünün **içindeki** dosya ve klasörleri GitHub deposunun köküne yükleyin. `index.html` kökte görünmeli.
3. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → GitHub deposunu seçin.
4. Framework preset: `None`; Build command: boş; Build output directory: `/` (arayüz kabul etmezse `.`). Deploy.
5. Pages adresiniz `*.pages.dev` olacaktır. Yayına çıkmadan metinleri ve iletişim bilgilerini gözden geçirin.

## Blog
İlk sürüm statiktir, CMS henüz kurulmamıştır. Yazı eklemek için `blog/` klasörüne yeni HTML dosyası ekleyip `blog/index.html` içindeki listeye bağlantı eklemek gerekir. Bu iki işlemi GitHub web arayüzünden yapabilirsiniz; daha sonra kolay editör kurulabilir.

## Önemli
- Örnek yazı ve iletişim bilgileri yayın öncesi tamamlanmalıdır.
- Özel alan adına geçerken URL yönlendirmelerini, canonical URL'leri ve Search Console'u birlikte ayarlayın.
- GitHub deposu public olduğunda dosyalar herkese açıktır. Danışan bilgilerini veya gizli dosyaları yüklemeyin.
- Özel alan adı henüz olmadığı için sitemap.xml eklenmemiştir.
